# summit-lab

A research lab run by AI agents: head researchers, departments and workers, with shared memory that limits who can read what.

Started on Nov 14, 2026, during a weekend AI research hackathon in San Francisco. Work in progress.

**Start here:** [explanation.md](explanation.md) is the working log. It records the layout, every decision and the reason for it, what the agents did, open issues and the sources behind each choice.
